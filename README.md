# Hanuman Travels - Ultra Luxury Intercity Platform

A state-of-the-art digital experience built for **Hanuman Travels**, featuring:
- **Cinematic Apple-Style Preloader**: Custom SVG canvas loading animation.
- **Image Sequence Engine**: 300-frame 3D fleet animation engine.
- **Choose Your Ride**: Interactive split layout vehicle configurator with morphing FLIP animations.
- **Real Leaflet Map Explorer**: CartoDB dark tile map with custom text-only node markers and glowing route particle flows across AP & Telangana.
- **Premium Reservation System**: Apple/Tesla-inspired 40%/60% asymmetric booking dashboard with instant WhatsApp dispatch (`+91 6300071224`).

## Tech Stack
- **Framework**: Next.js 15 (App Router)
- **Styling**: TailwindCSS & Custom Glassmorphism System
- **Animations**: Framer Motion & HTML5 Canvas
- **Maps**: Leaflet.js & CartoDB Dark Matter
- **Icons**: Lucide React

## Deployment
Deployed on Vercel.
